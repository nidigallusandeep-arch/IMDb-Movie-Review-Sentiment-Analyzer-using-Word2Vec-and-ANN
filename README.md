# 🎬 IMDb Movie Review Sentiment Analyzer using Word2Vec and ANN

An AI-powered **Movie Review Sentiment Analysis** application that classifies IMDb movie reviews as **Positive** or **Negative** using Word2Vec word embeddings and an Artificial Neural Network (ANN).

The application allows users to enter a movie review and instantly predict its sentiment through an interactive Streamlit web interface.

## 🚀 Live Demo

🔗 **Try the Application:**  
https://imdb-movie-review-sentiment-analyzer-using-word2vec-and-ann-y5.streamlit.app/

## 📌 Project Overview

Sentiment Analysis is an important Natural Language Processing (NLP) task used to identify emotions and opinions expressed in text.

In this project, we use:

- **Word2Vec** to convert text words into numerical vectors.
- **Artificial Neural Network (ANN)** to classify movie reviews.
- **Streamlit** to create an interactive web application.

The model predicts whether a given movie review expresses positive or negative sentiment.

## 🎯 Project Objectives

- Build a movie review sentiment classification system.
- Apply NLP preprocessing techniques to text data.
- Generate word embeddings using Word2Vec.
- Train an ANN model for sentiment classification.
- Deploy the trained model using Streamlit.
- Provide real-time predictions through a user-friendly interface.

## 🧠 Model Architecture

### 1. Natural Language Processing

Text preprocessing includes:

- Lowercase conversion
- HTML tag removal
- Special character removal
- Tokenization
- Stopword removal

### 2. Word2Vec

Word2Vec converts words into dense numerical vectors that represent semantic relationships between words.

**Embedding Dimension:** 100

Sentence representation is generated by averaging the available word vectors.

### 3. Artificial Neural Network (ANN)

The ANN architecture:

| Layer | Configuration |
|---|---|
| Input Layer | 100 Features |
| Dense Layer 1 | 128 Neurons, ReLU |
| Dropout | 0.3 |
| Dense Layer 2 | 64 Neurons, ReLU |
| Dropout | 0.2 |
| Output Layer | 1 Neuron, Sigmoid |

**Loss Function:** Binary Crossentropy  
**Optimizer:** Adam  
**Activation:** ReLU and Sigmoid

## ⚙️ Installation and Setup

### Step 1: Clone the Repository

```bash
git clone https://github.com/nidigallusandeep-arch/IMDb-Movie-Review-Sentiment-Analyzer-using-Word2Vec-and-ANN.git
```

### Step 2: Navigate to Project Folder

```bash
cd IMDb-Movie-Review-Sentiment-Analyzer-using-Word2Vec-and-ANN
```

### Step 3: Create Virtual Environment

```bash
python -m venv movie_env
```

Activate the environment:

**Mac / Linux**

```bash
source movie_env/bin/activate
```

**Windows**

```bash
movie_env\Scripts\activate
```

### Step 4: Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 5: Run Streamlit Application

```bash
streamlit run app.py
```

The application will open in your browser.
